# diff-speed-entry

Entry for make.fun's `diff-speed-01-run-20261126` bounty: a dependency-free `solve.js`
that re-implements makefun-diff 1.0.0's line-diff semantics (Myers search, deletion wins
ties, makefun-diff/1 patch format) and returns answers byte-identical to the house
baseline, faster (interned line ids, typed V diagonals, prefix/suffix trim, no public
diff libraries, no vendor code copied).
